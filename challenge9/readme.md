# Inventory Copy Analysis

## Overview
This program demonstrates the difference between shallow copy and deep copy using a simple inventory dataset.

## Concept
- Shallow copy duplicates only the outer structure.
- Nested objects remain shared between original and shallow copy.
- Deep copy creates a completely independent duplicate.

## Workflow
1. Create initial inventory data.
2. Generate shallow and deep copies.
3. Apply updates based on roll number logic.
4. Compare original data with modified versions.
5. Analyze how changes affect each copy.

## Key Observation
- Changes in shallow copy affect original data.
- Changes in deep copy do not affect original.

## Output
- Displays original, shallow, and deep datasets.
- Shows number of changed and unchanged items.
- Provides a short analysis summary.
